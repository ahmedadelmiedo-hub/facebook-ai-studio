# أسرار البرية

قناة عربية بأسلوب هجين يجمع السرد الوثائقي والتشويق القصصي، بصوت راوٍ رجالي، وثلاثة فيديوهات طويلة أسبوعيًا.

## سير الإنتاج
1. اختيار موضوع موثق عن الحياة البرية والطبيعة.
2. كتابة سيناريو عربي أصلي مع افتتاحية مشوقة ومصادر للمراجعة.
3. تقسيم السيناريو إلى مشاهد مع وصف بصري لكل مشهد.
4. توليد التعليق الصوتي العربي بصوت رجالي.
5. تركيب الفيديو والترجمة العربية.
6. تجهيز ثلاثة Shorts مشتقة.
7. مراجعة بشرية ثم النشر على YouTube.

## التشغيل
شغّل GitHub Actions باسم **Secrets of the Wilderness — Build Episode** يدويًا. أول تشغيل ينشئ حزمة السيناريو والمشاهد والترجمة كـ Artifact.

## المتطلبات
أضف `GROQ_API_KEY` إلى GitHub Actions Secrets لتوليد السيناريو. لا توجد مفاتيح أو رموز وصول محفوظة في الملفات. توليد الصوت والفيديو والرفع التلقائي يحتاج ربط مزود صوت وحساب YouTube؛ لن يُدّعى أنه يعمل قبل إعداد هذه الأسرار واختبارها.
