# أسرار البرية — نظام إنتاج وثائقيات الحياة البرية

مشروع Python لإعداد وثائقيات عربية قصيرة عن الحيوانات وسلوكها وبيئاتها، باستخدام صوت الراوي المعتمد في Fish Audio.

## إعدادات القناة

- الاسم: **أسرار البرية**
- اللغة: العربية الفصحى المبسطة
- الأسلوب: وثائقي هجين؛ سرد سينمائي مع شرح علمي
- الراوي: صوت رجالي عبر Fish Audio
- الحلقة التجريبية: **الأخطبوط: عبقري الهروب**، 8–9 دقائق مستهدفة
- وتيرة الإطلاق: حلقتان طويلتان أسبوعيًا في المرحلة التجريبية

## الأسرار المطلوبة

أضف القيم في GitHub → Settings → Secrets and variables → Actions. لا تضع مفاتيح API في الملفات أو المحادثة.

| Secret | الاستخدام |
|---|---|
| `FISH_API_KEY` | مفتاح Fish Audio |
| `FISH_VOICE_ID` | Voice ID للراوي |
| `SCRIPTWRITER_API_KEY` | مفتاح مزود كتابة السيناريو المتوافق مع OpenAI |
| `YOUTUBE_CLIENT_ID` | OAuth Client ID |
| `YOUTUBE_CLIENT_SECRET` | OAuth Client Secret |
| `YOUTUBE_REFRESH_TOKEN` | تفويض قناة YouTube |

## طريقة التشغيل والمراجعة

الـWorkflow يدوي فقط؛ لا يوجد نشر تلقائي مجدول في هذا الفرع.

1. افتح GitHub Actions واختر **أسرار البرية - إنتاج بمراجعة بشرية** ثم Run workflow.
2. اترك `approve_asset_id` فارغًا لإنشاء المعاينة.
3. نزّل Artifact الناتج وشاهد الفيديو كاملًا.
4. إذا وافقت على الفيديو، شغّل Workflow مرة أخرى واكتب قيمة `asset_id` نفسها في `approve_asset_id`.
5. عندها فقط يحاول النظام رفع الأصل الموافق عليه إلى YouTube.

تشغيل `dry_run=true` يختبر التخطيط دون استدعاء Fish Audio أو YouTube.

## البنية

- `core/script_writer.py`: مخطط الوثائقي وكتابة النصوص.
- `core/story_planner.py`: مدة الحلقة وخطة الجدولة.
- `core/autopilot.py`: توليد الصوت وتركيب الفيديو.
- `core/automation.py`: إنشاء المعاينة والتحقق من موافقة النشر.
- `core/youtube_publisher.py`: رفع الأصل الموافق عليه فقط.
- `content/story_queue.json`: قائمة موضوعات الحياة البرية.

## ملاحظة مهمة عن المرئيات

المسار الحالي يعيد استخدام محرك الفيديو الموجود بالمشروع. لم يُضف بعد موصلًا يجلب لقطات حياة برية مرخصة تلقائيًا؛ لذلك يجب اعتبار أول معاينة اختبارًا تقنيًا للصوت والتركيب، لا نسخة نهائية بصرية، إلى أن يُستكمل مصدر اللقطات والتحقق من تراخيصها.
